# USB Remote

Chromebook の Chrome から USB 機器を選び、自宅の Ubuntu へ共有する仕組みを目指すプロジェクトです。

## 現在の状態

初期プロトタイプです。

- WebUSB が利用できるか確認
- Chrome の USB デバイス選択画面を表示
- このサイトにアクセスを許可した機器を一覧表示
- USB の接続・切断を画面に反映

**現時点では Ubuntu への USB データ転送、USB/IP 連携、共有・解除は未実装です。** 一覧に表示されたことは、その機器を完全にリモート利用できることを意味しません。

## GitHub Pages

Repository の Settings → Pages で、Deploy from a branch を選び、Branch を `main`、Folder を `/(root)` にして保存すると公開できます。

公開後は HTTPS のページを Chrome で開いてください。WebUSB はセキュアコンテキストとユーザー操作が必要です。

## 使い方

1. HTTPS でページを開く
2. 「USB機器を選択」を押す
3. Chrome の選択画面で機器を選び、許可する
4. 許可済み機器が一覧に表示される

## 対応範囲と制限

WebUSB はすべての USB 機器を汎用的に扱える仕組みではありません。OS が管理する USB メモリ、オーディオ、カメラなどは、ブラウザから直接利用できない場合があります。ChromeOS の端末管理ポリシーでも制限される可能性があります。

次の段階では、機器クラスごとの実現性を確認しながら Ubuntu 側エージェントとの暗号化通信、認証、個別共有・解除を設計します。USB 機器をネットワークへ公開する機能には、接続元の認証とアクセス制御が必須です。

## 開発方針

- Reemo の稼働環境には影響を与えない
- Docker は使用しない
- まず読み取り・認識確認から段階的に実装する
- 対応できない USB 機器を「対応済み」と表示しない
